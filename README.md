# Smokeleaf Plus

An advanced, low-impairment alternative to vanilla smokeleaf. The Smokeleaf Cigar delivers the same mood boost as a regular joint, but with almost no downside — perfect for colonists who need to stay functional.

## Effects

| | Smokeleaf joint | Smokeleaf Cigar |
|---|---|---|
| Mood | +13 | +13 |
| Consciousness | −30% | −5% |
| Moving | −10% | none |
| Hunger | +30% | +10% |
| Pain | −20% | −20% |
| Sleep fall rate | 100% | 95% |
| Tolerance per dose | 3% | 1% |

## Recipe

- Crafts from 8x smokeleaf leaves
- Drug Lab, Cooking skill

## Addiction profile

Shares the vanilla Smokeleaf chemical. Lower risk than regular joints:

- Addictiveness: 0.015 (vs 0.020)
- Minimum tolerance to addict: 20% (vs 15%)
- Tolerance per dose: 1% (vs 3%)

## Compatibility

- RimWorld 1.5 and 1.6
- XML-only — no C# required
